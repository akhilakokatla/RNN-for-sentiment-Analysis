# RNN Sentiment Analysis
A Natural Language Processing (NLP) project that uses a **Recurrent Neural Network (RNN)** to classify text sentiment as **positive or negative**.

## Project Overview
The project preprocesses text data, converts words into numerical representations, and uses an RNN-based deep learning model to learn sentiment patterns from the text.

## Technologies Used
* Python
* Pandas
* NumPy
* NLP
* PyTorch
* RNN
* Text Preprocessing

## Workflow
1. Load and explore the dataset
2. Clean and preprocess text data
3. Tokenize the text
4. Convert text into numerical sequences
5. Prepare training and testing data
6. Build the RNN model
7. Train the model
8. Evaluate model performance
9. Predict sentiment for new text

## Features
* Text preprocessing and tokenization
* RNN-based sentiment classification
* Binary sentiment prediction
* Model training and evaluation
* Prediction on new text samples

## Result
The trained RNN model learns patterns in text and predicts whether a given sentence expresses **positive or negative sentiment**.
